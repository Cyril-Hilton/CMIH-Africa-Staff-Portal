# Clock-in flow and attendance visibility · 26 October 2026

The task creation page used links labelled “Clock In” and “Clock In Now” that only navigated to the dashboard. Staff then encountered a second clock-in action. The post-save action now submits attendance directly and redirects to the dashboard with the completed attendance state. Subsequent requests return the existing clock-in without overwriting its time or objective. Task eligibility now consistently includes work created by the person, including managers assigning work to others. Attendance takes precedence over task eligibility when rendering the task page, so an existing clock-in is never hidden by an empty task list.

HR's full staff roster no longer has a constrained internal scroll area. The clock-in log explicitly describes that it contains actual clock-ins only; non-clockers are visible in the full roster above. All 19 active office staff were reconciled against the live roster. Suspended accounts remain historical where logs exist; field merchandiser attendance remains separate. CVO, Super Admin and the presentation service account remain excluded.

Production's staff scheduler entry was empty and no dedicated automatic clock-in job existed. The existing `autoclock:superusers` command was run to restore the authorized automatic attendance records, and a dedicated daily 00:01 hosting job was added without restarting unrelated scheduled jobs. Cyril Hilton and Curtis Barnor each have exactly one On Time record today and appear correctly in HR attendance. Existing automatic time-generation behavior is unchanged.
